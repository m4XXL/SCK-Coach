# SCK-Coach V0.3

- Taktikzeichner: Strafraumbogen am rechten Strafraum des ganzen Spielfelds wird nur außerhalb des Strafraums gezeichnet.
- Taktikzeichner: Strafraumbogen im halben Spielfeld geometrisch korrigiert und auf den sichtbaren Außenbereich begrenzt.
- Neue Übung: Mehrfach-Upload für Screenshots, Bilder und PDF-Dateien.
- Dateigrenzen: maximal 2 MB pro Datei und 4 MB insgesamt, da die App weiterhin ohne Server im LocalStorage arbeitet.
- Anhänge erscheinen in der Übungsdetailansicht; Bilder werden als Vorschau angezeigt, PDFs können geöffnet oder gespeichert werden.

- Datenmigration: Neue Bibliotheksübungen werden beim ersten Start von V0.3 ergänzt, ohne selbst angelegte Übungen zu löschen.

Start: `index.html` im Browser öffnen.
